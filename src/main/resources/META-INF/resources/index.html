A pure-MCP console over stateless HTTP

This page is an MCP client: it calls tools/list and tools/call straight against the server's /mcp endpoint over Streamable HTTP — no session, no initialize handshake required. Because each request is fully independent, the platform load-balances across replicas trivially and scales to zero when idle. Built on Quarkus for instant startup and a tiny footprint; data lives in a shared PostgreSQL.
