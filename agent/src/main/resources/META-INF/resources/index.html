An agent in front of a stateless MCP fleet

This console is the agent app. It calls a server-side MCP client (managed McpClient), which reaches a fleet of stateless MCP servers through a load balancer. Because the servers keep no session state, every tools/call can land on a different replica — the platform load-balances trivially and scales to zero when idle. Built on Quarkus; tool data lives in a shared PostgreSQL.

💬 Ask the Agent supervisor → specialist sub-agents → MCP fleet

Ask a logistics question in plain English. A supervisor agent (OpenAI) routes it to the right specialist — Shipment, Inventory, or Exceptions — each of which calls the stateless MCP fleet for live data.

Where is shipment HLX-10032291 and will it be on time? How much stock of SKU-COLD-4521 is available? What open exceptions need attention in APAC? Estimate FRA → YYZ for 620 kg and check HELIOS-AIR's SLA.
